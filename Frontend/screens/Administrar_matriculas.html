Carga masiva mediante Excel

Descarga la plantilla, completa las filas y sube el archivo para procesar las matrículas.

Formato requerido

nombre cedula accion
  • La acción debe ser MATRICULAR o RETIRAR.
  • Si una cédula no existe y la acción es MATRICULAR, se creará una cuenta de estudiante.
  • Las cuentas nuevas recibirán una contraseña temporal única.
  • El archivo de resultados incluirá las contraseñas temporales de las cuentas creadas.
  • El límite por archivo es de 1,000 filas y 5 MB.
